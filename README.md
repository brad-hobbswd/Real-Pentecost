# Real Pentecost

**Real Pentecost: More Than a Moment, A Life in the Spirit** is a Scripture-centered companion book and study website inviting readers to examine the biblical pattern of Pentecost through repentance, the saving name of Jesus Christ, the gift of the Holy Ghost, the apostles' doctrine, fellowship, prayer, holiness, and faithful witness.

## Live Website

https://brad-hobbswd.github.io/Real-Pentecost/

## Website Contents

- The book, including prologue, foreword, introduction, twelve chapters, and epilogue
- Biblical resources on Acts 2:38, Acts 2:42, repentance, the Holy Ghost, prayer, fellowship, holiness, and apostolic doctrine
- Devotionals, FAQ, search, author, and contact pages

## Technology

This is a static website built with HTML, CSS, and JavaScript and published through GitHub Pages.
